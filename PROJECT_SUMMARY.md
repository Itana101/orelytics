# Project Summary — Orelytics

## Project name
Orelytics: Mining Economics Intelligence

## Short description
An interactive educational dashboard that explores how commodity price, production, operating cost, and annualized capital assumptions influence a simplified mine's economic outcome. It combines responsive web development, data visualization, mining engineering context, and economic scenario analysis.

## My role
Independent project developer. Built the front-end interface, scenario calculation logic, chart rendering, stress-test controls, CSV export, documentation, and GitHub Pages setup.

## Technologies
HTML5, CSS3, vanilla JavaScript, SVG, CSV export, GitHub Pages.

## Main learning outcomes
- Translating a real-world engineering/economic question into a small computational model.
- Separating model inputs from calculated outputs.
- Visualizing synthetic time-series data and scenario metrics.
- Exploring sensitivity to price and operating-cost shocks.
- Communicating assumptions, limitations, and data provenance clearly.

## Important honesty note
This is a self-directed educational prototype using synthetic illustrative market data. Do not claim it is used by a real mine, that it predicts commodity prices, or that it is a certified feasibility tool. When submitting it, describe the work and implementation year accurately.
